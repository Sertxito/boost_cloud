# Security Policy

## Supported Versions

This project currently supports the latest published version on npm.

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Report privately using one of these options:

1. GitHub Security Advisory (preferred).
2. Direct contact with repository owner `@Sertxito`.

Include:

- Affected file/path.
- Reproduction steps.
- Impact assessment.
- Proposed fix (if available).

## Response Targets

- Initial acknowledgement: within 3 business days.
- Triage and severity assignment: within 7 business days.
- Fix timeline depends on severity and complexity.
